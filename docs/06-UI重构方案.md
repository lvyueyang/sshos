## 1 背景与目标

当前前端存在：基础组件缺失（shadcn/ui 未落地）、组件层级混乱、主题 token 体系残缺、深浅硬编码混用、图标体系混乱（emoji / Unicode / 首字母）、动画与交互反馈缺失、配色单调。

本次为**破坏性重构**（不考虑历史兼容），一次合并推进。重构边界：SFn / Server Route 架构、策略引擎挂载边界、桌面范式（一连接一 Tab）、流式数据不进全局 store、xterm 动态 import、包边界 importProtection（ssh2 / pi-coding-agent 不进 renderer）**均不动**。

## 2 现状审计（问题清单）

### 2.1 基础组件缺失
- 无 `components.json`、`src/components/ui/`、`lib/utils.ts`（`cn()` 不存在），docs §1.2 承诺的 shadcn design token 未落地
- 表单控件靠 `globals.css` 裸 `input/select/textarea` 全局样式，无焦点环 / 禁用 / 校验态 / 尺寸变体

### 2.2 组件层级混乱
- 4+ 套手写弹层重复：`file-dialogs.tsx` 的 `Modal`、`Sidebar.tsx` 的 `GroupDialog`、`ApprovalDialog`、`ConnectionDrawer`、`SettingsWindow`，遮罩 + 卡片结构各自实现
- 桌面内容硬编码分发表：`Desktop.tsx` 的 `WINDOW_CONTENT/PANEL_CONTENT`、`Taskbar.tsx` 的 `STATUSBAR_CONTENT`、`ICON_COLOR` 写死在组件里，app 插件只声明 manifest，视图由外壳手工映射（违背插件化意图）
- `components/` 28 个文件平铺；`TitleBarButton / DesktopIcon / GroupHeader / ConnectionItem` 均为组件内私有
- 重复工具函数：`formatBytes` / `usagePct` 各两份、时间格式化散落

### 2.3 主题布局混乱
- 仅 20 个 CSS 变量，缺 shadcn 全量 token（secondary / muted-foreground / popover / input / ring / radius / destructive 等全缺）
- 深浅不兼容硬编码：`hover:bg-white/10`、Taskbar `rgba(13,17,23,0.85)`、MonitorPanel `rgba(22,27,34,0.72)`、桌面图标 `#e6edf3`、`ICON_COLOR` 内 `#3aa0c4/#8b5cf6`（light 下失效）
- 样式三套并存：内联 `style={{ color: "var(--x)" }}` + tailwind 类 + 硬编码 hex
- 终端主题硬编码 `theme: { background: "#000000" }`，未与 UI 主题解耦（docs §5.10 未实现）
- 主题状态二元 `"light" | "dark"`，无多主题扩展点

### 2.4 图标体系混乱
- 混用 emoji（📁📄🔗🕘）、Unicode（✕ ✎ ⚙ ＋ ⋮⋮ ⠿ ◆ □ ❐）、字母首字（Logo"S"、桌面图标 `label[0]`）
- `manifest.icon` 字段声明但从未被消费

### 2.5 动画与交互反馈缺失
- 仅 `pulse` keyframe + `animate-spin`；窗口 / 抽屉 / 弹窗均瞬态，hover 反馈生硬
- loading 全文本（"加载中…/测试中…"），无 spinner / skeleton；`ConnectionDrawer` 保存失败直接 `console.error` 静默吞错
- docs §8.3/8.4 的 AI 命令卡片（safe/review/block 视觉）完全未实现
- 无全局 toast、无骨架屏、无窗口焦点/失焦差异、无空态复用

### 2.6 其他
- docs §1.3 字体规范（InstrumentSans / JetBrainsMono）未落地
- 大量硬编码中文字面量，i18next 覆盖率低
- 无统一 focus-visible ring、滚动条样式、`prefers-reduced-motion`

## 4 主题系统设计

### 4.1 单一事实：shadcn 全量 token
采用 shadcn **new-york + Tailwind v4** 规范，`:root` = light / `.dark` = dark：

- **色板**：`background / foreground / card / card-foreground / popover / popover-foreground / primary / primary-foreground / secondary / secondary-foreground / muted / muted-foreground / accent / accent-foreground / destructive / destructive-foreground / border / input / ring`
- **项目语义色家族**（解决配色单调）：`success / warning / danger / info` 各自带 `-foreground`（文字）、`-soft`（浅底）、`-border`（描边）派生，覆盖 Policy 三态（safe/review/block）、连接状态、告警、审计色标
- **数据可视化色板**：`chart-1..chart-5`（Monitor 图表、分组色条、Provider 徽标），HSL 派生与主题联动
- **品牌色**：`app-terminal / app-files / app-monitor / app-ai / app-logs / app-clock`（桌面图标配色，替换 `ICON_COLOR`）
- **形状 token（圆角）**：单一事实 `--radius`（默认 8px，对齐 docs/03 §1.4），shadcn 派生档映射 Tailwind `rounded-*`：
  - `--radius-sm = calc(var(--radius) - 4px)` → 4px：标签 / 徽标
  - `--radius-md = calc(var(--radius) - 2px)` → 6px：按钮 / 输入框
  - `--radius-lg = var(--radius)` → 8px：卡片 / 面板
  - `--radius-xl = calc(var(--radius) + 4px)` → 12px：窗口
  - scheme 与 palette 均可覆盖 `--radius`（如圆润 / 锐利主题），组件只写 `rounded-sm/md/lg/xl`，禁止散值
- **间距 token（密度）**：4px 基准网格（docs/03 §1.4），Tailwind v4 `--spacing` 为间距基础单元（默认 0.25rem = 4px），`data-density` 三档覆盖全局密度：`compact → 0.2rem` / `normal → 0.25rem` / `comfortable → 0.3rem`；palette 可覆盖。语义间距常量（防散值）：`space-1` 4px（图标间隙）/ `space-2` 8px（桌面图标间距、控件内边距）/ `space-3` 12px（窗口内距）/ `space-4` 16px（区块内距）/ `space-6` 24px（区块间距）。组件一律用 spacing utility 整数档或语义常量
- **字号 token（字阶）**：rem 体系 + 根 font-size 全局字阶缩放（`appearance.fontScale`，支持更大字号无障碍场景）。项目字号表对齐 docs/03 §1.3：10px `--text-2xs`（辅助角标）/ 12px `--text-xs`（桌面图标标签、任务栏、状态栏、时间戳）/ 14px `--text-sm`（表单、正文次要、代码）/ 16px `--text-base`（正文）/ 18–32px 标题档（H2 26 / H1 32）。终端独立：xterm `fontSize` 读 `--terminal-font-size`（默认 14px）
- **阴影 token**：`--shadow-xs/sm/md/lg` 层级（窗口浮起用 lg，卡片用 sm，聚焦窗口加深）
- **终端独立色板**：`--terminal-bg / fg / ansi-0..15`（docs §5.10 双主题分离落地，xterm theme 读取）
- **动效 token**：`--duration-fast/base/slow` + `--ease-standard/emphasized`
- **桌面背景**：`--desktop-bg` 渐变 token 保留

### 4.2 充分利用 Tailwind v4
- `@import "tailwindcss"` + `@theme inline { --color-background: var(--background); ... }` 映射为 `bg-background / text-foreground / border-border / text-success / bg-destructive / ring-ring` 等语义类；`--radius-*` 派生映射 `rounded-*`；`--text-*` 映射字号档；`--spacing` 驱动全局间距密度
- 组件**全面移除内联 `style={{ color: "var(--x)" }}`**，改用语义类；圆角 / 间距 / 字号同样禁止内联散值，一律走对应 token 类
- 引入 `tw-animate-css` + `clsx` + `tailwind-merge`（`cn()`）

### 4.3 多主题扩展机制
- 根元素四维度：`class`（scheme：light/dark，沿用"切换只改 class"决策）+ `data-theme`（palette：`github` 默认，未来 nord 等）+ `data-density`（间距密度：compact/normal/comfortable）+ 根 font-size（字阶：`appearance.fontScale`）
- 新增主题 = 追加 `[data-theme="nord"] { ... }` 覆盖文件；明暗两 scheme 可叠加任意 palette；palette 可同时覆盖圆角（`--radius`）、间距（`--spacing`）、字号（`--text-*`）
- 存储演进：`appearance.theme` 由 `"light"|"dark"` 升级为 `{ scheme, palette }`（旧字符串值兼容映射为默认 palette）；新增 `appearance.density`、`appearance.fontScale` 独立偏好
- 新增 `theme/theme-provider.tsx` 提供 `useTheme()`（scheme + palette 切换、持久化、`prefers-color-scheme` 兜底）与 `useDensity()/useFontScale()`（密度 / 字阶偏好）

## 6 图标体系（@remixicon/react）
- 官方 React 包 `@remixicon/react`，named import 天然 tree-shake
- `manifest.icon` → 图标映射：`terminal→RiTerminalLine / folder→RiFolder2Line / spark→RiSparkling2Line / chart→RiLineChartLine / list→RiListUnordered / clock→RiTimeLine`
- 建立 `AppIcon` + `Icon` 统一封装，替换全部 emoji / Unicode / 首字母
- 规格：`size`（默认 16/20，桌面图标 24）+ `currentColor` 继承语义色

## 7 动画与过渡体系（motion）
- 引入 **`motion`**（v13，原 framer-motion，`import { motion, AnimatePresence } from "motion/react"`）；SSR 下 motion 组件客户端渲染（沿用 xterm 动态 import 模式）
- 令牌化动效：`--duration-fast:120ms / base:200ms / slow:300ms` + `--ease-standard/emphasized`
- 落地清单：
  - **窗口**：打开 `scale(0.96)+fade` 入场、关闭退场、最小化/还原、聚焦置顶
  - **抽屉/弹窗**：Drawer 滑入滑出、Dialog scale+fade
  - **桌面图标**：hover 上浮、选中高亮、双击弹起反馈
  - **任务栏/Tab**：活跃指示条平滑滑动、关闭动画
  - **列表**：文件 / 消息 / 日志行增删用 `AnimatePresence + layout`
  - **监控**：数字 count-up、折线动画、进度条过渡
  - **状态灯**：连接中 pulse（保留）
- 全量遵守 `prefers-reduced-motion`

## 10 风险与约束
- **不动的边界**：SFn / Server Route 架构、策略引擎挂载边界、桌面范式、流式数据不进全局 store、xterm 动态 import、包边界 importProtection
- **SSR 兼容**：motion / vaul 等客户端库须规避 SSR 直出（沿用动态 import 模式）
- **性能内建**：shadcn 按需、@remixicon tree-shake、TanStack Charts / monaco 类重库动态 import、大列表虚拟化
- **Token 破坏性重命名**（`--bg→--background` 等）：全仓同步替换，一次性完成
- **主题存储兼容**：`appearance.theme` 旧值迁移到 `{ scheme, palette }`
