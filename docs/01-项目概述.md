# SSH 可视化终端管理工具 · 项目概述

开源 · 非商业 · 像操作系统一样操作 SSH 连接的 Linux · AI 原生集成。

## 1 项目定位

把 SSH 终端从「命令行-only」升级成「可视化操作系统式」的交互体验——SSH 是底层驱动，类 OS 界面是外壳，AI 是让远程管理真正智能化的入口。

本项目是**远程 Linux 的桌面外壳**：通过纯 SSH 协议、零 agent，把远程服务器的文件、软件、系统状态以桌面隐喻的方式可视化呈现。用户像操作本地电脑一样操作远程 Linux；AI 作为「第二消费者」接入同一套读写网关，提供理解、诊断、命令生成能力。

## 2 核心功能

- **SSH 终端**——流式交互、低延迟，中文输入无乱码，支持多窗口同时使用
- **文件管理**——目录浏览、上传/下载、重命名/删除/新建、压缩/解压；远程压缩工具缺失时自动降级提示
- **系统监控**——CPU / 内存 / 磁盘 / 网络实时指标，桌面状态卡片 + 完整仪表盘
- **连接管理**——密码 / 密钥两种认证，连接分组、配置持久化，发行版识别与缺失依赖安装引导
- **AI 助手**——自然语言操控远程系统，所有命令经策略引擎分级拦截（危险命令直接拒绝 / 敏感命令人工审批 / 安全命令直接放行），全程审计
- **日志审计**——AI 交互、终端命令、策略决策三类结构化日志统一查询

## 3 运行形态

以**纯 Web 服务**方式运行，浏览器打开即可使用，无需安装客户端。使用启动密码登录；连接配置与日志等数据保存在服务端本地，不上传任何云服务。

## 4 交互范式

**一个 SSH 连接 = 一个 OS 桌面 Tab**：每个连接打开独立的桌面空间，通过桌面图标、应用窗口、任务栏完成所有操作，不做多页面路由切换（界面细节详见[界面设计](./03-界面设计.md)）。
